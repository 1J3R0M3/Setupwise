# Legacy PowerShell version

This folder contains the original **Winget Installer** – a PowerShell script with a WPF window – from which Setupwise evolved.
It is kept for reference and is no longer developed. Use the Setupwise app instead.

Run it with `Installer.bat` (bypasses the execution policy for this one call only).
`Installer.ps1` must stay saved as **UTF-8 with BOM**, otherwise Windows PowerShell 5.1 shows broken umlauts.
